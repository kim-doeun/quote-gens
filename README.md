# Lomin 견적서 발급 및 관리 시스템

Lomin(로민) 회사의 영업대표들을 위한 **견적서 발급 시스템**이자, 회사 전체의 **견적 이력 관리 시스템**입니다. 정적 웹사이트(HTML/CSS/JS) + RESTful Table API로 구현되었습니다.

---

## 1. 프로젝트 목표

- 영업대표가 고객사별로 신속하게 **표준화된 견적서**를 발급
- 견적서를 **S/W 라이선스(제품)** 와 **개발비(서비스/인건비)** 두 축으로 명확히 구분해 산정
- 회사가 모든 **견적 발행 이력을 검색·필터·상태관리**
- S/W 라이선스 카탈로그, 인건비 등급별 단가표, 고객사 정보를 재사용해 입력 효율 향상
- 발행된 견적서를 실제 견적서 양식(예시 이미지)과 동일한 형태로 **화면 확인 및 인쇄/PDF 저장**

---

## 2. 완료된 기능

### 🧭 공통 레이아웃 - 좌측 메뉴(사이드바)
- 모든 페이지 좌측 사이드바(`js/common.js`의 `renderSidebar`)는 **접기/펼치기(collapse) 가능**합니다.
- 데스크톱(1024px 이상)에서는 사이드바 우측 상단에 원형 토글 버튼이 표시되며, 클릭 시:
  - **펼침 상태**: 로고, 회사명, 메뉴 라벨, 로그인 계정 정보가 모두 표시되는 기존 레이아웃 (너비 16rem)
  - **접힘 상태**: 아이콘만 남고 텍스트 라벨은 숨겨지는 좁은 레이아웃 (너비 5rem), 각 메뉴에 `title` 툴팁 제공
- 접기/펼치기 상태는 `localStorage`(`lomin_sidebar_collapsed`)에 저장되어 **페이지를 이동하거나 새로고침해도 유지**됩니다.
- 모바일/태블릿(1024px 미만)에서는 토글 버튼이 숨겨지고, 기존처럼 사이드바가 상단에 항상 펼쳐진 상태로 표시됩니다(레이아웃에 영향 없음).

### 📊 대시보드 (`index.html`)
- 전체 견적서 수, 이번 달 발행 금액, 승인된 견적 수, 진행중 견적 수 요약 카드
- 최근 6개월 월별 발행 금액 바 차트 (Chart.js)
- 상태별 견적 분포 도넛 차트
- 최근 발행 견적서 리스트 (클릭 시 상세 이동)

### 📝 견적서 발급 (`quote-new.html`)
- **견적서 기본 정보**: 견적명(프로젝트명), 참조(선택 입력) 입력
- 등록된 고객사 선택 시 담당자/연락처/이메일/주소 자동 입력 (직접 입력도 가능)
- 견적담당(영업대표) 정보 입력 (이름/이메일/연락처)
- **발급상태 지정 필드 없음** — 견적서는 항상 저장 시 `발송전` 상태로 생성되며, 상태 변경은 발급 이후 「견적 이력 관리」 화면에서만 수행하며, 견적서 문서(인쇄/PDF 포함)에는 전혀 노출되지 않습니다.
- 견적 항목을 **2개 섹션으로 분리 입력**:
  - **01. S/W 라이선스** — 등록된 S/W 라이선스 카탈로그에서 선택하거나 직접 입력. 항목/구분(운영·개발)/수량(Q)/소비자단가(LP)/소비자금액(Q×LP)/제안단가(P)/제안금액(Q×P)
  - **02. 개발비** — 등록된 인건비 단가표(등급별)에서 선택하거나 직접 입력. 업무활동/담당/등급(특급·고급·중급·초급)/수량(M/M, 인월 단위 소수 입력 가능)/소비자단가(LP)/소비자금액(M/M×LP)/제안단가(P)/제안금액(Q×P)
- 우측 요약 패널에서 S/W 소계, 개발비 소계, 공급가액, 부가세(율 조정 가능), 총 합계금액을 실시간 계산
- 결제조건, 고객 공개용 비고, 내부 전용 메모(비공개) 입력
- 견적번호 자동 생성 규칙: `QT-{연도}-{월}-{3자리 순번}` (예: `QT-2026-08-001`, 연/월별로 순번 초기화)
- 저장 시 `quotes`(헤더 + 소계) 및 `quote_items`(항목, `item_type`으로 제품/서비스 구분) 테이블에 함께 저장
- **견적서 저장(발급) 완료 시 Slack 채널 알림 자동 발송** (`js/common.js`의 `notifySlackQuoteIssued`)
  - Slack **Incoming Webhook** 방식 사용 (지정된 하나의 채널에만 새 메시지로 게시 — 스레드 답글 아님)
  - 알림에 포함되는 정보: 견적번호, 고객사명, 견적명, 총 제안 금액(VAT 포함), 담당자, 견적서 상세 페이지 바로가기 링크
  - 알림 전송은 저장 성공 이후 비동기로 수행되며, 전송 실패 시에도 견적서 저장/화면 이동에는 영향 없음(콘솔에 에러만 로그)
  - ⚠️ 보안 참고: 정적 사이트 특성상 Webhook URL이 클라이언트 JS 코드에 노출됩니다. 해당 URL은 지정된 채널에만 메시지를 게시할 수 있는 제한된 권한이므로 상대적으로 안전하지만, 유출이 우려되는 경우 Slack에서 Webhook을 재발급(무효화)하고 코드를 갱신해야 합니다.

### 📁 견적 이력 관리 (`quotes.html`)
- 견적번호/고객사/영업대표 통합 검색
- 상태별, 영업대표별 필터 및 발행일/금액 정렬
- 검색 결과 건수 및 합계 금액 실시간 표시
- 목록에서 바로 상태 배지 클릭 → 상태 변경 모달 (발송전/발송됨/내부협의중/계약됨/만료됨)
- 상세보기, 삭제(소프트 삭제) 지원

### 📄 견적서 상세/인쇄 (`quote-detail.html?id={견적ID}`)
- 첨부 예시 이미지와 동일한 형식의 정식 견적서 문서 레이아웃:
  - Lomin 로고 + 상단 **견적 정보표** (예시 이미지와 동일한 표 형식): 견적명 / 수신 / 참조 / 연락처(고객) — 견적담당 / 연락처 / 이메일(영업대표) — 사업자등록번호 / 회사명 / 대표이사 / 주소 / 대표전화(Lomin 고정 정보)
  - 견적번호 / 발행일 / 유효기한 요약 카드 (상태는 표시되지 않음 — 내부 관리 전용)
  - **「01. S/W 라이선스」** 표 (항목/구분/수량Q/소비자단가LP/소비자금액Q×LP/제안단가P/제안금액Q×P) + S/W 제안 금액(VAT 제외/포함) 소계 바
  - **「02. 개발비」** 표 (업무활동/담당/등급/수량M-M-Q/소비자단가LP/소비자금액MM×LP/제안단가P/제안금액Q×P) + 개발비 제안금액(VAT 제외/포함) 소계 바
  - 최종 **「총 제안 금액」** 박스 (VAT 제외 / VAT 포함 금액을 강조 표시)
  - 결제조건, 비고
- **견적 상태는 견적서 문서(화면/인쇄/PDF)에 표시되지 않습니다.** 화면 상단의 상태 드롭다운(`no-print` 영역)으로만 내부 관리하며, 변경 즉시 반영됩니다.
- 브라우저 인쇄 기능으로 PDF 저장/출력 (`window.print()`, 인쇄 시 사이드바 등 UI 숨김)
- 내부 메모는 화면에서만 노출, 인쇄물에는 출력되지 않음
- 견적서 삭제
- **엑셀(.xlsx) 다운로드 — 템플릿 기반**: 화면 상단 "엑셀 다운로드" 버튼 클릭 시, 미리 정의된 엑셀 템플릿(레이아웃/색상/테두리/로고 등 서식 고정)에 실제 견적 데이터를 채워 넣어 `.xlsx` 파일로 즉시 다운로드
  - **ExcelJS**(CDN 라이브러리) 사용, 서버 없이 클라이언트에서 파일 생성
  - **템플릿과 데이터 로직이 분리된 구조**:
    - `js/quote-excel-template.js` — "템플릿" 정의 파일. 문서 전체 레이아웃(로고 배치, 헤더 배너, 견적정보표, 항목표 헤더/바디/소계, 총액 박스, 결제조건·비고, 하단 안내문)과 모든 서식(배경색/테두리/폰트/정렬/컬럼너비/셀 병합)을 함수 단위로 정의. 서식만 변경하려면 이 파일만 수정하면 됨.
    - `js/quote-detail.js`의 `exportQuoteToExcel()` — 템플릿의 `buildQuoteWorkbook(quote, items)`를 호출해 워크북을 완성한 뒤, Blob으로 변환해 다운로드 트리거만 담당
  - 포함 내용: Lomin 로고(가로형, 96×36) + "Document AI 솔루션 전문기업" 부제목 + "견 적 서" 타이틀 배너, 견적서 헤더 정보표(견적번호/발행일/유효기간/사업자등록번호/견적명/수신/참조/연락처 등을 5행×3열 통합 그리드로 배치 — 별도 요약카드 없음), 「01. S/W 라이선스」/「02. 개발비」 항목 표(색상 헤더 + 테두리 + 소계 배경색 포함, 항목/업무활동과 설명 컬럼 모두 자동 줄바꿈 적용) 및 각 섹션 소계(VAT 제외/포함), 총 제안 금액 박스(VAT 제외/포함 모두 폰트 13사이즈로 통일, 강조 서식), 결제조건, 비고, 하단 안내문
  - 금액 컬럼은 `#,##0"원"` 통화 서식 자동 적용
  - **자동 줄바꿈 컬럼의 행 높이 자동 확장**: 엑셀은 `wrapText: true`만으로는 행 높이를 자동으로 늘려주지 않으므로, 견적 정보표의 **주소/견적명 등 값 컬럼**과 「01. S/W 라이선스」/「02. 개발비」 표의 **항목·업무활동/설명 컬럼**은 텍스트 길이·컬럼 너비를 기반으로 예상 줄 수를 계산해(`js/quote-excel-template.js`의 `estimateWrappedLines`/`rowHeightForWrappedText`) 행 높이를 자동으로 늘려줍니다(한글 등 전각 문자는 폭 2배로 가중치 적용). 내용이 짧으면 기존 최소 높이를 유지하고, 길수록 필요한 줄 수만큼 행이 커져 텍스트가 잘리지 않습니다.
  - 파일명 규칙: `견적서_{견적번호}_{고객사명}.xlsx`
  - 향후 문서 디자인을 변경하려면 `js/quote-excel-template.js`의 `XLSX_COLORS`(색상), `QUOTE_XLSX_COLUMN_WIDTHS`(컬럼 너비), 각 `build*()` 함수(레이아웃)만 조정하면 됩니다.
- **인쇄/PDF 가독성 개선**:
  - 표 본문 글자 크기 1단계 축소: 14px → 13px, 설명/보조 텍스트 12px → 11px
  - 표 전체 셀 패딩 축소(헤더/본문 모두 여백 최소화하여 더 많은 정보를 한 화면/한 페이지에 표시)
  - 금액(원화 숫자)은 `whitespace-nowrap`으로 줄바꿈 없이 항상 한 줄로 표시
  - 「01. S/W 라이선스」/「02. 개발비」 표의 본문 행에도 헤더와 동일하게 셀 테두리(실선)를 적용해 표 전체에 격자선이 표시됨
  - 「01. S/W 라이선스」 표의 "설명" 컬럼 너비를 확대(약 28%)해 긴 설명 텍스트의 가독성 향상

## 4. 데이터 모델 (RESTful Table API)

### `products` (S/W 라이선스 카탈로그)
| 필드 | 타입 | 설명 |
|---|---|---|
| name | text | 라이선스/제품명 |
| category | text | 라이선스 / 구독 |
| unit | text | 판매 단위 (EA, License 등) |
| list_price | number | 소비자단가 (LP) |
| unit_price | number | 제안단가 (P) |
| description | text | 설명 |
| is_active | bool | 판매중 여부 |

### `labor_rates` (인건비 단가표) — 신규

## 6. 아직 구현되지 않은 기능 / 제한사항

- **로그인/권한 관리**: 현재는 별도 인증 없이 모든 방문자가 전체 기능에 접근 가능합니다 (정적 사이트 특성상 서버 인증 불가). 영업대표별 접근 제한이 필요하면 Hosted Deploy의 **Access Rules**(로그인 기반 접근 제어)를 별도로 적용할 수 있습니다.
- **이메일 발송**: 견적서를 고객에게 이메일로 직접 발송하는 기능은 없습니다 (인증 필요한 이메일 API 연동은 정적 사이트에서 불가). 인쇄/PDF 저장 후 수동 발송을 권장합니다.
- **전자서명/승인 워크플로우**: 고객의 온라인 서명, 내부 결재선 등의 워크플로우는 없습니다.
- **다중 통화**: 원화(KRW) 기준으로만 계산됩니다.
- **버전 관리(견적서 수정 이력)**: 견적서 수정 시 이전 버전을 보관하지 않고 현재 값만 유지합니다.
